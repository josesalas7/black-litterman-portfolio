# Black-Litterman Portfolio Optimization
 
Implementação do modelo de **Black-Litterman (1992)** para otimização de portfólio, combinando retornos de equilíbrio de mercado com views do investidor (qualitativas ou quantitativas) para gerar alocações mais estáveis e diversificadas do que a otimização clássica de Markowitz.
 
O projeto inclui:
- Função de otimização com suporte a views do gestor e views quantitativas
- Framework de backtest comparando a estratégia contra o benchmark (portfólio neutro)
## Referências
 
- Black, F. & Litterman, R. (1992). *Global Portfolio Optimization.*
- Idzorek, T. M. (2004). *A Step-By-Step Guide to the Black-Litterman Model.*
